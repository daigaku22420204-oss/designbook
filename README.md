# デザインブック

見つけたデザインを写真で採集して、説明と「ここが好き」、#タグを残せる招待制のデザイン帳です。
仲間どうしで公開した採集を見せ合い、いいねやコメントができます。手書き・付箋・図形でまとめられる自分だけのアイデアノート付き。

- 画面：GitHub Pages
- データ・写真・ログイン：Supabase（無料プラン）

公開と招待の方法は [SETUP.md](SETUP.md) を見てください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `config.js` | Supabase の接続情報と、機能のオン・オフ・上限の設定 |
| `backend.js` | アプリと Supabase をつなぐ部分 |
| `supabase/setup.sql` | データベースの準備（招待リスト・権限ルール・容量の上限・公式アカウントの作例） |
| `assets/` | アイコンと公式アカウントの作例画像 |
| `manifest.webmanifest` | スマホのホーム画面に追加したときの設定 |
